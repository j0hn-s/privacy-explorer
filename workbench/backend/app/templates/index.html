Workbench

A local sandbox for the privacy-explorer framework. Author Privacy Cards, run them through the YAPS rule engine, browse the T0–T4 reference materials, and ingest empirical results from privacy-eval/ into a card's risk_calibration block.

WIP — research scaffolding, not production. See limitations.md for what this is not.

Browse saved cards Create a card Browse T0–T4 reference

How this fits with the rest of the repository

  • Reference data (T0–T4) is read live from /repo/data/*.yaml.
  • Rules are read live from /repo/yaps/rules/rules.yaml on each evaluation.
  • Engine is the canonical yaps/engine/risk_engine.py imported directly — identical semantics to the CLI.
  • Persistence: Elasticsearch indices cards-v1, card-versions-v1, evaluations-v1.
  • Schema versions: 1.0, 1.1, and 1.2 (with the risk_calibration block).
